# Amazon-Customer-Reviews-Sentiment-Analysis-NLP


Project Overview

This project predicts the sentiment of customer reviews (Positive, Neutral, Negative) using Natural Language Processing (NLP) techniques.

Models used: Logistic Regression & Multinomial Naive Bayes

Feature extraction: TF-IDF vectorization,

Text preprocessing: lowercasing, punctuation removal, stopwords removal, lemmatization.

#Dataset Source: Amazon Product Reviews


#Evaluation:
Model	Accuracy:Logistic Regression 0.87 
Precision:0.86
Recall:0.87
F1-Score:0.86


Model	Accuracy:Naive Bayes 0.85
Precision:0.84
Recall:0.85
F1-Score:0.84

Sample Predictions:

"This product is amazing and very useful!" → Positive

"The item broke after one week. Very disappointed!" → Negative
